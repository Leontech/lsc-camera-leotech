unsquashfs / mksquashfs – squashfs-tools 4.6.1 (GPL-2.0-or-later), static ARMv5 builds (gzip + xz)
Source code: https://github.com/plougher/squashfs-tools/tree/4.6.1
Build script: sdkit/tools/build_squashfs_arm.sh (+ armv5_sync.c, zlib 1.3.1, xz 5.6.3)
These programs are used unmodified on the camera to unpack the camera's own original firmware
and to pack the new image. They are separate programs, not linked with the rest of this project.
